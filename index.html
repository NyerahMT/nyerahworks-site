Current iOS ports

Two open-source C++ applications adapted for Apple mobile platforms.

Engine Simulator · iOS

Engine Simulator for iOS

01

Port of Ange Yaghi’s Engine Simulator to iPhone and iPad. The iOS layer adds ARM64 builds, touch input, application lifecycle handling, Files integration, SDL3/Metal rendering, native audio output, and mobile engine loading while retaining the simulator core and its .mr scripting system.

Original Ange Yaghi / engine-sim
Platform iOS / iPadOS / ARM64
Integration SDL3 · Metal · Files · TestFlight

Principia · iOS

Principia for iOS

02

Port of the community-maintained Principia physics sandbox to iOS. The work covers Apple build integration, lifecycle and resume behavior, mobile input and interface adaptation, device-specific rendering fixes, and repository structure intended to keep the iOS changes close to upstream.

Original Bithack / Principia community
Codebase C++ / SDL
Port focus iOS platform layer / upstream compatibility
