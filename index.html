Services

Porting and iOS integration

01

Make it build

Compatibility review, build-system adaptation, dependency work, Apple bundle configuration, and an ARM64 path from the existing source tree to a real device.

02

Make it behave

Lifecycle, rendering, touch input, audio, file access, packaging, signing, and device-specific problems that appear once desktop software is living on iOS.

03

Keep it maintainable

Platform-specific changes kept deliberate and contained so the iOS port can continue following an active upstream project without unnecessary fork drift.
